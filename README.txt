PUBLISH ON VERCEL (MAC BEGINNER GUIDE)

1. Download my-ma-lokkhi-vercel.zip.
2. Open Downloads and double-click the ZIP to extract it.
3. Open the extracted my-ma-lokkhi folder. It contains index.html, style.css, script.js, README.txt and WEBSITE_PROMPT.txt.
4. Visit https://github.com/ and sign in.
5. Click the + icon (top-right) → New repository.
6. Name it my-ma-lokkhi. Choose Public or Private. Click Create repository.
7. In the new repository, click Add file → Upload files.
8. In Finder, open the extracted my-ma-lokkhi folder. Press Command+A to select the five files and drag them into GitHub's upload area. Upload the files themselves, not the ZIP file.
9. Scroll down and click Commit changes.
10. Visit https://vercel.com/ and choose Continue with GitHub.
11. In Vercel, click Add New → Project. Find my-ma-lokkhi and click Import.
12. If asked, use Framework Preset: Other; Root Directory: ./; leave Build Command empty; leave Output Directory empty (or enter . if required).
13. Click Deploy. When it finishes, click Visit. Your live website URL is ready to share.

No coding, Terminal, npm install, database, API key, or paid service is needed. If you get stuck, take a screenshot and ask for the next click-by-click instruction.
